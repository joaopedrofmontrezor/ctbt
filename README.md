# CTBT Beach Tennis - Landing Page

Bem-vindo ao repositório da Landing Page oficial do **CTBT Beach Tennis**, localizado em Matão, SP.
Esta página foi desenvolvida com foco em alta performance, SEO e um design premium para proporcionar a melhor experiência de usuário.

## 🚀 Tecnologias Utilizadas

- **[Next.js](https://nextjs.org/)** (App Router)
- **React**
- **Vanilla CSS (CSS Modules)** para estilos customizados e alta flexibilidade
- **Vercel** (Pronto para hospedagem com Zero Config)

## 📁 Estrutura de Pastas

A estrutura de pastas foi projetada para ser modular, escalável e de fácil manutenção, seguindo as melhores práticas do mercado de desenvolvimento web:

```
src/
├── app/                  # Roteamento e layouts globais (Next.js App Router)
│   ├── globals.css       # Estilos globais e variáveis de design (Cores, Fontes)
│   ├── layout.tsx        # Layout principal e configurações de SEO/Meta Tags
│   └── page.tsx          # Página principal (Home) orquestradora
├── components/           # Componentes modulares independentes
│   ├── Arena/            # Seção de informações das quadras e modalidades
│   ├── Footer/           # Rodapé com links e contatos
│   ├── Gastronomy/       # Seção do Bar e alimentação
│   ├── Header/           # Menu de navegação responsivo
│   ├── Hero/             # Capa principal impactante da landing page
│   ├── Location/         # Mapa e endereço
│   ├── Teachers/         # Seção de apresentação dos professores
│   └── WhatsAppButton/   # Botão flutuante interativo
public/
└── images/               # Arquivos estáticos e imagens
```

## 🛠️ Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/joaopedrofmontrezor/ctbt.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado.
